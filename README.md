# kaeyounglian.github.io

Personal portfolio & project showcase — built with React 19 + Vite + Tailwind CSS v4 + framer-motion. Deployed on GitHub Pages.

## Projects Featured

- **GlassToDo** — macOS desktop app (Tauri v2 + React). Frosted-glass todo with spring physics, recollectable trash, date completion tracking.
- **CS2 Market Analyzer** — Django + Steam API. Real-time candlestick charts, AI-powered price predictions, multi-key rotation.
- **PingPong Mate** — WeChat mini-program + Django backend. Match friends, track games, manage court reservations.
- **Workday Allocator** — Django + DRF. Smart work hours allocation with weighted priority scoring.

## Tech Stack

| Layer | Stack |
|-------|-------|
| Framework | React 19 |
| Build | Vite |
| Styling | Tailwind CSS v4 |
| Animation | framer-motion |
| Hosting | GitHub Pages (Actions) |

## Development

```bash
# Install
npm install

# Dev server
npm run dev

# Build
npm run build
```
