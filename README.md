# kaeyounglian.github.io

Personal portfolio — dark cinematic design, built with React 19 + Vite 6 + Tailwind CSS v4 + framer-motion.

A creative studio–style landing page showcasing projects I've shipped:

- **GlassToDo** — Tauri desktop app with frosted-glass UI, spring physics, recollectable trash
- **CS2 Market Analyzer** — Django + Steam API: real-time candlestick charts + AI price predictions
- **PingPong Mate** — WeChat mini-program: match friends, track games, court reservations
- **Workday Allocator** — Django API: weighted priority scoring for smart scheduling

## Design

Inspired by the Prisma creative studio aesthetic — dark, cinematic, noise-textured. Fonts: Almarai + Instrument Serif (italic). Every section animated with framer-motion: WordsPullUp, scroll-linked character opacity, staggered card reveals.

## Tech

| Layer | Stack |
|-------|-------|
| Framework | React 19 |
| Build | Vite 6 |
| Styling | Tailwind CSS v4 |
| Animation | framer-motion |
| Icons | lucide-react |
| Hosting | GitHub Pages (Actions) |

## Build

```bash
npm install
npm run build    # outputs to _site/
```
