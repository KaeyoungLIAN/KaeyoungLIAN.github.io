**PingPong Mate** is a WeChat Mini Program for ping-pong enthusiasts — find matches, track scores, and manage court bookings.

### Features

- **Pair matching** — Find ping-pong partners based on skill level and availability
- **Game tracking** — Win/loss records, match history, player stats
- **Court management** — Reservation system with real-time availability
- **WeChat Mini Program** — Native WeChat experience with OAuth login
- **Django REST API** — Token-based authentication, SQLite backend

### Tech stack

Frontend is a native WeChat Mini Program (WXML/WXSS), backend is Django 4.2 with Django REST Framework. Communication via RESTful API with Token Auth.
